# Genshin Tools 1.7.0 — 游戏 7.2 / FufuLauncher 1.7.2.2 适配

- 跟进 FuFuPlugin 1.7.2（构建 1.7.2.2），动态识别新版 62 项 INI 设置；升级保留兼容的用户配置。
- 安装、启动与回滚同时检查插件声明的游戏版本和本地精确兼容清单，拦截跨游戏版本的旧插件。
- 新版主插件及嵌入签名模块增加 Authenticode 离线复核，不自动导入证书；信任检查失败时保留原安装。
- 资源下载显示已校验复用量，修正复用数据的速度统计与完整缓存的空间预检。
- 官服切换无需联网获取 B 服元数据，并事务清理新增的旧渠道 SDK 文件，保留无关文件。
- 修正进程退出回归测试的固定等待时间和子进程清理。
- 修正新版 PowerShell 构建后环境变量“未设置/空值”的恢复差异，并加入发布回归检查。

下载附件中的 Windows x64 便携 ZIP，并使用同名 `.sha256` 核对完整性。
主插件仍按需下载，不随本项目发布包分发。缺少签名信任链时会显示错误；纯净启动保持可用。

适配依据、固定哈希和功能取舍见 `docs/upstream-adoption-2026-11-05.md`。
真实游戏、反作弊兼容性、不同 Windows/DPI/UAC 环境仍需实际使用验证；离线签名检查不等于实时吊销查询。
本次最终发布验证采用后台模式，前台窗口、置顶、焦点切换与真实输入测试明确跳过。
