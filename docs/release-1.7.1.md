# Genshin Tools 1.7.1 — 快捷键名称显示与编辑

- 主插件配置中所有 `key` 字段以按键名称显示，例如 `121` 显示为 `F10`，无需查询键码。
- 支持直接输入 `F10`、`Insert`、`Space` 等名称，忽略名称大小写和首尾空格；保留多位旧键码输入兼容。
- 数字行 `7` 与小键盘 `Num 7`、左右修饰键分别识别，修复导航键与小键盘名称混淆。
- 浏览器键、多媒体键、ABNT 和额外 ISO 按键使用独立名称，避免 Windows 扫描码别名导致保存为其他按键。
- INI 仍保存插件要求的原始数字键码；已有配置无需迁移，注释和无关字段保留。
- 无效名称或磁盘保存失败时恢复原显示与内存值；补充原生编辑控件、重开与全部可识别键名称往返测试。

下载附件中的 Windows x64 便携 ZIP，并使用同名 `.sha256` 核对完整性。

自动验证使用后台模式；真实输入、可见窗口生命周期及真实游戏/DPI/UAC 等人工矩阵不计入本次通过结果。详细执行结果见本地 `artifacts/s13/automated-verification.json`。
